# 熱量存錢筒（CalorieBank）

台灣在地熱量／蛋白質紀錄 App，電子雞式小豬撲滿陪伴。Kotlin／Traditional Chinese。

## v2.4.3

- 可刪除誤記：主畫面四格明細 bottom sheet 支援左滑／🗑、可愛確認框、短「復原」snackbar
- 運動／鍛鍊列表與「紀錄明細」歷史（近 14 天）同樣可刪；刪過去日子會重算該日淨值並調整總存款
- Health Connect 活動熱量可「忽略今日」（可復原）

## v2.4.2

- 主畫面上方四格可點：跳出可愛 bottom sheet 說明怎麼算
- 今日攝取列出每筆食物；蛋白質依餐別小計；運動含 MET／HC；鍛鍊列部位與分鐘
- 總存款仍開啟每日總結

## v2.4.1

- 首頁不再顯示建議卡；建議改在「每日總結」
- 每日總結：攝取／蛋白質／運動／鍛鍊／淨值／總存款＋三則建議規則
- 觸發：約 21:30 通知、隔天第一次打開先看昨天總結（在 BMR 金幣前）、點總存款或設定／存摺入口

## v2.4.0

- 新主畫面：上方今日攝取／蛋白質／運動／鍛鍊，中央放大總存款
- 總存款下方每日建議（低於 BMR 溫柔提醒危害；熱量進帳提醒注意健康；維持健康缺口則稱讚）
- 目標：每天維持熱量缺口，但攝取不低於 BMR

## v2.3.1

- 所有體型暫統一用可愛 normal 小豬（胖瘦立繪之後再加）
- 新增台灣常見份量表（270 項）：地瓜一顆、白飯一碗、雞蛋一顆等，自動換算熱量／蛋白質
- 搜尋支援俗名（地瓜／番薯…），空搜尋優先顯示常見食物

## v2.1 重點

- 首頁只放小豬：會走來走去、翻轉、搖晃、打滾、坐下／睡覺，不擋到底部按鈕
- 三大鍵：吃（搜尋／條碼／標示）、運動（有氧 MET）、鍛鍊（部位變壯疊圖）
- 存完運動／鍛鍊會跳出小豬稱讚動畫與隨機台詞；連續天數加強稱讚並給徽章
- 活動消耗：有手動紀錄時以手動為準，否則 Health Connect，避免重複計算
- 飽足／心情／體力；太久沒記飲食會通知
